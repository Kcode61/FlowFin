# FlowFin

FlowFin é uma aplicação completa para gerenciar finanças pessoais e de projetos.

O backend em Java Spring Boot fornece a API, controla autenticação e conecta dados de usuários, receitas, despesas e projetos.

O frontend em Next.js oferece a interface para cadastro, exibição de despesas, receitas, projetos e informações de perfil.

Use este repositório como ponto de partida para ver a integração entre as duas camadas e testar a experiência de um app financeiro simples.

Para rodar, abra cada pasta e use os comandos da tecnologia correspondente.
